# PlameApps — Offline

Полностью офлайн-версия PlameApps для GitHub Pages.

## В этой версии

- нет WebSocket;
- нет онлайн-сервера;
- нет GitHub API;
- нет GitHub-токена;
- игра работает в браузере без сервера;
- аккаунт сохраняется в `localStorage` устройства;
- повторная регистрация на этом устройстве блокируется;
- в профиле стартовый ГАЗОН NEXT 7м с верхним спальником;
- нажатие на машину открывает её характеристики;
- есть удаление аккаунта в настройках;
- после удаления повторная регистрация блокируется.

## GitHub Pages

Загрузить содержимое проекта в репозиторий → `main`.

Затем:
**Settings → Pages → Source → GitHub Actions**

Workflow автоматически опубликует `index.html`.

## Важно

Офлайн-аккаунт хранится только в браузере конкретного устройства.
Если очистить данные сайта браузера, локальное сохранение тоже будет удалено.
